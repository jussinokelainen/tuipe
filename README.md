TUIPE
=====
Simple tui typing test/trainer, with different difficulties and modes.

Installation
------------
#### Arch linux:
```bash
git clone git@github.com:jussinokelainen/tuipe.git
cd tuipe/pkgbuild/arch
makepkg -si
```

#### Manually:
```bash
git clone git@github.com:jussinokelainen/tuipe.git
cd tuipe
cargo install --path .
```

Uninstalling:
-------------

Via pacman or with cargo.
